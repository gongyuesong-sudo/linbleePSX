## 对话框模板结构 [观察 + 部分未知]

模板为 DLGTEMPLATEEX 风格头 (version=1, signature=0xFFFF), 但控件项是
16 字节头变体: `{DWORD style, SHORT x,y,cx,cy, DWORD id, class原子, 文本原子}`
—— 与标准 DLGITEMTEMPLATE(带 cstyle) 不同, 疑似自定义编译器/打包器改写。
证据例 (30008 "请放入游戏 CD"):

```
标题 "bleem!" @30, 字体 8pt "MS Sans Serif"
控件: id=4 "&Retry" BUTTON  |  id=3 "Quit" BUTTON
      id=0 STATIC "Please insert a game CD into your CD-ROM drive!"
      + 编辑框/图标控件 (0x0082/EDIT, 0x0080/BUTTON 原子)
```

头字段精确语义 [未知], 故重建工程**逐字节保留原模板**, 不用 windres 重写。
