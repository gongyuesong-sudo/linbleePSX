# 38 — H-21/H-22 家族终局：中断流排除项与关门判据（task-049 a2，2026-10-31）

## 1 分发面地图（本征反汇编）
- BIOS IRQ 二级分发按 I_STAT 位掩码派发（ROM C1 内）：
  `bit0→0xBFC038338`（源0）、`bit1→0xBFC03869C`（源1）、`bit2(vblank)→0xBFC038338 族`、
  `bit3→0xBFC038B60`、`bit4→0xBFC038B9C`（判据 `and a0,lui/ori 掩码` 链 @ROM 0x1CA60..0x1CAD8）。
- ROM 读 I_STAT/I_CTRL 非直接 `lui 0x1f80+0x1070`（全镜像扫描仅 0x60/0xF90 触 0x1060）——
  经指针寄存器间接，静态定位高成本，故走动态注入实验判据。

## 2 H_IRQ 注入实验（机制，env=每 N 块，上限 8 次）
- 注入内容：`I_STAT|=2`（vblank）+ `I_CTRL|=2` + `Cause.IP2` + `SR.CEL` + pc←异常表
  （[0xFFFE0130]→[0x130]→0x1E988 回退，EXN 真派发同路）。
- 运行实证：`IRQINJ#1..8` 全部触发、每次成功派发 `h=bfc1e988`；
  **UNIQ 474 块 census 与基线逐位差分 = 0 行**，停机面（0x1014/ra=4/hk=2）不变。

## 3 终判（task-049 关门判据）
中断/节拍流**不是**当前墙的钥匙：注入 IRQ2 被 BIOS 分发器静默消费，因其回调注册列表
（vblank callback stack）从未被建立——注册动作在 C2 init 契约深处，该面被 H_C2HOME ack
截断（docs/36 §6、docs/37 §6 合取）。三条排除项至此集齐：
① 设备复位/CDROM/C2SEC 状态词（048 3/3）② ra=4 帧槽单点（050 3/3）③ 中断/节拍流（049 本判）。
**唯一剩余充分面 = 自研完整 C2 初始化契约**（回调注册 + 线程上下文 + 事件泵三一体），
任何单面注入均为惰性。H-21/H-22 阶段按 AGENTS 预登记条件关门：继续推进需以
"契约完整化"为独立立项（工程量≈重写 libgpu/libetc 初始化语义），超出 demo 逆向知识工程目标；
游戏内容运行维持 DuckStation 路线（docs/33）。
