## 2. 交权行语义（本楔最重要一行）
`add $0xfa00,%esi` 中 **0xFA00 = overlay 文件起点 = 解压后宿主主体在映射内的落点**。
二段先在别处(VirtualAlloc 页区)解包，再跳入 base+0xFA00 区执行——
"二段→解压→宿主主体 VA"启动链闭合。

## 3. 否证
内嵌 **MZ×2(ov+0x1b64f/0x29b3d) 验伪**：PE 签名缺失/mach=0——载荷内高熵噪声，
无隐藏第二 PE。

## 4. 解析注记（防再踩）
objdump 字节列后**多空格再 tab**——正则须 `[0-9a-f]{2}(?: [0-9a-f]{2})*\s*\t`；
长指令字节换行 + 连续重复区 `...` 压缩行都要跳过。首轮 19 指令假象即此 bug。

## 5. 楔4 定靶

② 对照三流金标准(473,417B)与 ov 载荷区偏移，锁定压缩流在 overlay 的精确三元组；
③ host 侧 LZ 位引擎与 PSX 侧位引擎(docs/06)异同判定。
