# 46 — M-4 BIOS 侧 rootcall 44-cmd 实现映射（task-060，SESSION-69）

C2 发出的**全部 50 个桩点 / 44 个 distinct cmd**（docs/45 §1）在真机安装态的派发链与 handler 入口全解析。

## 1. 三族派发链（golden RAM 向量页实证）

| vec | 向量页跳板 | 派发块 | 表基+索引 |
|---|---|---|---|
| 0xA0 | RAM[0xA0]: `lui t0,0; addiu t0,0x5c4; jr t0` | RAM 0x5C4 | `[0x200 + cmd*4]` |
| 0xB0 | RAM[0xB0]: → RAM 0x5E0 | RAM 0x5E0 | `[0x874 + cmd*4]` |
| 0xC0 | RAM[0xC0]: → RAM 0x600 | RAM 0x600 | `[0x674 + cmd*4]`（= C2HOME 已消费面）|

派发块统一 6 词形（基址 <0x10000 故无 lui）：`addiu t0,zero,base; sll t1,t1,2; add t0,t0,t1; lw t0,[t0]; nop; jr t0`（t1=cmd）。

## 2. 入口分布终判

- 50/50 全非零，**C1 核入口=50/50，空槽=0**（含 2 例 ROM 相对偏移形态，经 0xBFCxxxxx 镜像可解析）。派发块与 handler 入口均以 20-bit 掩码解 RAM 物理（`h&0xFFFFF`，kseg1 镜像 1:1）——本节及 host50 曾踩 29-bit 掩码致 phys 溢出之坑，已按实测修正。
- **终判**：引擎侧全部 44 个命令在 BIOS 均有真实现 handler 且表已装——H-24 关门判'BIOS 侧不缺'由静态升级为 **50/50 完备性实证**。
- RAM 壳 2 例（0xB0/0x5B、0xC0/0x0A 类）为 ROM 相对偏移语义（派发块 lui 域=0，`h<0x80000` 直用），同族可解析。
