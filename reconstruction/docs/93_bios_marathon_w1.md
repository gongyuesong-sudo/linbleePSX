# 93 — BIOS 长跑战役楔1：三修真值面，SCPH1001 从 88 步跑到 1000 万步零异常（task-112，SESSION-123）

## 1. 方法论：真 BIOS = 唯一现成的金标准测试套件
薄引擎五楔后合成分支全绿但**覆盖≠正确**。本战役改用 SCPH1001 真码长跑
（`--bios-run=N` 长跑侦察工具：异常 cause/epc/opcode 逐道报告 + 直方图），
每道墙=一个真值缺口，补齐后步数曲线推进——**可量化、可复跑、不可自欺**。

## 2. 步数推进曲线（本楔战果）
| 阶段 | 推进到 | 修复面 |
|---|---|---|
| 楔5 基线 | 88 步 | — |
| +RAM 全镜像折叠 | **81,898 步** | PSX 主 RAM=全地址空间 2MB 镜像：仅设备窗(0x1F800000-0x1F80FFFF)与 BIOS 512KB 窗例外。旧 translate"越 0x328400 即 BAD"过严，BIOS RAM 探测写 `sw $9,0x130($1=0xFFFE0000)`→0xFFFF0130 必地址错(cause=0x14)。`off = gpa & 0x1FFFFF` 折叠；0xBFC80000+ 亦折回 RAM(楔2 断言按真值改写) |
| +rfe 指令 | **1,000,000 步零异常** | `0x42000010`=**rfe**（R3000A CO special funct 0x10，PSX rootcall 返回，与 eret 同义）——旧核只认 0x18，BIOS RAM 侧 rootcall stub(`0x8001014`)每拍 trap10。rfe 命中后 BIOS 走通完整启动：自检→rootcall 表→设备初始化→主循环 |
| 长跑验证 | **10,000,000 步零异常 rc=0** | `sp=0x801ffe00 ra=bfc06868` 恒定=正常 idle 环；a0010ff0/k0974/... GPU+DMA 寄存器堆全被真码写过 |

## 3. 附带修正（同楔固化）
- **GTE 命令判定**：`rt==0 && rd==0 && sa==0` 归命令（SFTRGB funct=0 必须
  命中；mfc2 $0,gte[0] 无意义面让位——与真机编码冲突面一致）。楔5 的
  `f!=0` 规则曾把 SFTRGB 吞成 mfc2（e2 当场抓出）。
- `--bios-run=N` 为正式战役工具面（非一次性脚本），每楔复用。
