# 98 — BIOS 战役楔6a（侦察楔）：BIOS 健康主循环全判读 + 三勘正（task-117，SESSION-128）

## 1. 本楔零语义改动——把楔5"会聚"判读的模糊点全部钉死
TR/pchist/watch/dis 四证合查，BIOS 在 CMEXP 态的真实行为：

| 判读点 | 真值（本楔钉死） |
|---|---|
| 2M 步执行重心 | **rom=1.94M（97%）** = BIOS ROM 主流健康运转（GPU 探测、初始化组调用、服务例程高频复用），非漂移非卡死 |
| RAM 0x2170-0x217C "4 步环" | **正当 BIOS 堆清零 memset**（`addiu $5,-1 / sb $0,0($a0) / bgtz $5,-12 / addiu $a0,1`——a0=0x882B 递增、a1 倒计数大循环）——498 轮/万步 = 慢而非墙 |
| "CDROM 0x1C00 未触"勘正① | 主序 0x6874-0x6890 的"CDROM 组写"**实际目标 = 0x1F801D80/82/84/86（XA 音频域）+ 0x1F801070（I_STAT）**——DEV_TR 0x1d80 系 ×12 在案 = **该序列已完整执行**。楔3/楔5 的"未触 CDROM"是**把 0x1C00 命令寄存器与 0x1D80 音频寄存器混称**——0x1C00 命令寄存器在**无盘态本就不该被写**（合法行为）|
| "syscall 风暴"勘正② | 2.7M 步起 cause=20 周期 195 步 = **BIOS 事件循环节拍调用 A()（syscall→异常分发→RAM dispatch→rfe 归）**——异常是 rootcall 的**正常载体**，不是崩溃 |
| 勘正③ | 楔5 文档"exc=88736 线性缩放=活循环"结论**成立**，但当时误标"漂移后修复面"——本楔确证 = 健康轮询 |

## 2. 等待条件清单终版（替代 docs/96 W1-W3）
- **W1 stub 存活**：已被 CMEXP（cache 维护写弃）正确解决——机制与真机
  D-cache 隔离语义等价（RAM 向量在维护循环中免毁）。
- **W2 CDROM**：无盘态 BIOS **不发读命令 = 正确行为**（0x1C00 零访问是
  feature 不是 bug）。真机进 CD 播放器界面需 GPU 呈现面（未建模）。
- **W3 事件节拍**：A()/syscall 195 步周期 + 堆维护 + 字符串例程 = **本引擎
  已复现 BIOS 无盘 idle 的全部可观测 CPU 侧行为**。

## 3. 战役结论与楔7 候选
**PSX BIOS（SCPH1001 真码）在本薄引擎上已到达无盘态合法最深终态**——
