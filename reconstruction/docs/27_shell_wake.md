# 26 — 金标准 shell 唤醒与设备派发汇流（H-16a，SESSION-39）

## 1. 轮询环静态破译（金标准 RAM 反汇编）
shell 空闲环 `ram 0x3D6E0-0x3D740`：轮询变量 = **RAM 0x83C58 字节**（设备状态：0=启动中、
1=轮询中、**2=就绪运行**）；`bne/beq at=({0x83C58}==2)` 构成等待环，`0x3D714 bne z0,a0`
后还有二次确认读。注入语义：置 1（非 2）即脱离等待环进入**主循环体**。

## 2. 唤醒实证（POKE=1）
- 无注入：2000 块停留空闲页（零越页零失败，attempt2 活性结论保持）。
- `POKE=1`（0x83C58=1）：**390 块越出空闲页**、393 块深，停机 pc=`0x04500E81`。
- **汇流定案**：该终点与 INJ 设备槽注入（`bfc0d540` 读 0x60）的滑入终点
  `0x04500E81/0x04500ECC` **同一节点族**（0x4500e00页）——两条独立宿主驱动路径
  （轮询唤醒 / 设备槽读）进入**同一内核设备派发下游**，随后取到未 HLE 的事件回调指针
  （0x04500E81 > 2MB 非 RAM = EvCB 回调槽在纯 HLE 态未填，真机由 C2 shell 程序注册）。

## 3. 判异/边界
- shell 唤醒后**不经过 syscall/异常**（serves=0）：事件派发是直调链，宿主推进只需状态字节。
- 下一个 HLE 缺口（H-16b 候选）：EvCB 回调表项（0x4500e 节点族取指处）——
  需在金标准 RAM 内定位承载该指针的结构（EvCB @E000h+ 图, docs/18）并填合法目标。

## 4. 复验
`bash tools/validate_host27.sh`：轮询变量判读落档 + POKE 唤醒(越页>200、393 块级深度、
终点=0x4500e81 汇流锚) + 无注入活性回归。

## 5. H-16b 时基闭环（SESSION-39）
- 死模块判异：唤醒返回走 `jr ra`，ra=`0x044F4C01`=休眠调用者（C2 shell 模块，
  该段 RAM 金标准全零——模块未驻留快照）；直接滑行=零页 NOP 雪（0x80/块步进假码）。
- 抢占闭环模型：POKE(0x83C58=1) + ra=break 哨兵(0xBFC4C1B0) + 停机重导引
  (cp 快照恢复 + 块缓存 flush)。周期计数=ROM 窗内 hk=2 停机（哨兵命中）。
- 长跑实证：**30,000,000 块 = 5,999,980 完整唤醒-返回周期（20% 占空），fails=0**；
  300k 块 59,980 周期同比例。宿主时基可无限期驾驭金标准 shell 循环。
- 深层主体（loop body 之后的模块码）仍受 C2 模块驻留缺口阻塞（§3 EvCB/模块双缺口）。
