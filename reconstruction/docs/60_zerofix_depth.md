# 60 — H-26 楔2：ZEROFIX 语义定版（深度门）与 ctx24 分型终判（task-075，SESSION-84）

## 1. ZEROFIX 两版实验与语义腐蚀发现（本楔核心）
- v1（改道 SENT 后 continue）：SENT 窗是**真 ROM 地址**（ROM+0x4C1B0），改道控制流又泄回
  ROM 根call流 → 再死跳 201 次 → srv cap break。IRQ 族"触发 201"皆此伪象。
- v2（改道即完成 break）：语义干净化，但序列实验 `[00,12,1c,19]` 暴露**入眼即死被吞成假成功**
  （0x00 破坏 RAM 后 12/1c/19 blocks=0 全"转化"）——失败伪装完成 = 语义腐蚀，不可接受。
- **定版 = v2 + 深度门 `b>=1000`**：浅层死跳=真失败保留 ctx；深层死跳（服务体自然终点）=宿主接管
  v0=0。序列门复验：12/1c/19 回正 ctx（ok=1=0x00 自身）。孤跑转化锚 **6/24 不变**
  {19,43,45,4a,c0/2,c0/3}（0x19 恰在切换点 117,851 接管——语义正确的切换出口）。

## 2. ctx24 分型终判（ZEROFIXLOG 逐成员）
