# 66 — A2 第一砖：私有 VM 假说否证——五"栈"是 C2 运行时自生成的 MIPS 代码（task-081，SESSION-90）

## 1. 词法→反汇编双验（决定性）
`0x66C4` 帧区 40 词反汇编**全部合法 MIPS**，且语义自洽：
`sltiu at,v0,K / bne / beq / addiu v1,zero,n` 规律节奏 = **字符分类范围分派码**
（对 v0 逐区间 [0x40,0x7f,0x80,0xad,0xb8,0xc0,0xc8,0xcf,0xda,0xe9,0xf0,0xf8...] 跳转分表）。
尾部词亦 MIPS：`lui t6,0x0 / addiu t6,t6,0x7300 / lhu / slt`（含 docs/47 设备访问族形态）。
**勘正 docs/65 §2 两处定性**：
- "私有字节码指令流" → 标准 MIPS；
- "水位哨兵 0x93A20020" → 实为指令 `sb v0,0x20(sp)`（代码块首词，非 magic）。

## 2. 份数与出处
`sltiu` 块头 16B 在 golden 命中 4 处：`0x66CC / 0x6878`（栈 T0/T2）与 `0x42D2C / 0x42ED8`（0x42 副本区）；
**三流（含 relocated）0 命中** → 代码非来自 C2 流镜像 = **运行时生成（JIT/特化）产物**。

## 3. 重定性后的完整图景
C2 引擎 = 纯 MIPS 主程序 + **运行时代码特化器**：执行中把热点分派（字符分类等）
生成专用 MIPS 码块放入双份工作区（0x66xx 低区 / 0x42xxx 堆区），`0x6CE0` 表混合登记
代码块基址与栈指针（`[66C4,67B8,6870,6928,85D8,F40,85D4]`——前四是码块基址，
0x85D8 是真栈顶(全零区+0x85DC=0xE10)，与 docs/54 切换现场吻合）。
