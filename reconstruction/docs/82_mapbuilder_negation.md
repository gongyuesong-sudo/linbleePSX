# 82 — x86 战线楔7：双判据否证静态主循环 + PSX 内存映射构造器现形（task-099，SESSION-108）

## 1. 双判据扫描结果（否证性收敛）
s3 解压态 156K 行反汇编：回边 3,374 / scratch imm 宽引用 133（真 scratch 仅 7）。
**"回边环 × scratch 立即数"唯一交叉环 = 0x10B4E-0x10D15（s3+0x100 起 455B）**——
即楔6 状态块**初始化循环**，非主循环。其余 126 引用全为数据错位噪声（fistpll/adc 型）。
**结论（诚实）**：s3 主循环**不存在静态 scratch 引用**——运行期一切 PSX 访存经
基址寄存器+状态块 disp 翻译（表寻址），静态双判据对它**原理性失明**。

## 2. 本楔真收获：PSX 内存映射构造器（0x10BBA-0x10CFF）
该 init 函数现场构建**宿主↔PSX 地址翻译表**（状态块字段直写）：
```
+0x44 = RAM base(alloc 0x328400≈3.2MB)     +0x48 = RAM-0xBFC00000 (BIOS ROM 窗!)
+0x4C/+0x58/+0x54/+0x50/+0x60 = +1MB/+80000/+E0000/+800000 变体窗
+0x28 = scratch 基                        +0x2C = 基-0x1F800000 (MMIO 翻译常数!)
+0x24 = +0x1F800400 (GPU 端口基——H 时代 0x1F801040/0x1F801800 族之源)
+0x14/04/08/0C/10/18/20 = 0x9400 池七连 0xC00 块 (scratch 子窗表)
+0x30 = size<<12, +0x60 = +0x800000       分配全走 table[0] VirtualAlloc(0x1000a)×4 槽循环
```
**docs/39 契约图的 native 构造代码自此在手**——H-23/H-27 全部 MMIO 常量的出生地确认。

## 3. 楔8 定靶（判据已换血）
静态 imm 判据废弃。新方法：在 s3 大循环（>0x100、call≥20）内找**同一基址寄存器
对状态块 disp(0x24/0x2c/0x44/0x48/0x28) 族的读簇**——候选池=§2 字段 disp 匹配的
大循环（预备数据：大循环 top 带 call 密度 300+/63KB 已列出，见 /tmp 扫描输出复算于 host90）。
内层再按"每拍写 C2 状态词"模式（A3 节拍 3-4 块）与 vblank 节流串型收敛。
