# 68 — A3 楔2：MainRun 宿主桥打通，主运行首次跑穿亿块（task-084，SESSION-93）

## 1. 桥的实现（`H_SVCLOW`，零 JIT 改动）
htrace 的 `host_service_cb` 是 **x86 原生函数指针**（真引擎直接 call 宿主机器码），
fwd 纯 MIPS 模拟语境无法照搬。等价物 = **guest 侧 thunk 注入**：
`H_SVCLOW[=base@end]`（默认 `0x100@0x200`）把 BLEEM 宿主服务表窗全填
`jr ra / nop` 交替双字——任何 `jr t9` 落窗即合法"服务返回"（v0 保持调用方值，
即默认成功核）。32 个 thunk，`fwd_init` 末尾注入。

## 3. 新墙定性：异常向量页黑洞
100M 末态 `endpc=0x80` = RAM 向量页 `lui k0,0x1a00` 异常处理入口——
主循环此刻滞留于异常处理路径（候选机制：某异常反复触发 → handler → ERET → 再异常）。
这不是死跳（kind=0，指令合法流），是**活循环黑洞**。
楔3 靶点 = 异常分型：读 `cop0[13]`(Cause)/`cop0[14]`(EPC)/`cop0[12]`(Status) 终态
+ 向量页第一分支去向，判定异常类型（地址错/TLB/保留指令）与 EPC 归属模块。
