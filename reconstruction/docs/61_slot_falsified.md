## 3. 否证与修正（本楔主判）

填槽后批次态恒 ok=2。b0/0c 深推取证给出真阻因：
`EMITFAIL pc=0x10C op=0x4 ra=bfc00e6c`（×201 定态）——收敛点是 **ROM putchar 链把
RAM[0x10C] 当执行落点**（docs/52 实证该窗 = 引擎堆"指针+小值配对表"，[0x10C]=4 非零小整数，

→ 18 成员的收敛三型（printf 设备语境 / 线程切换 / 堆对象活值）**全部是运行期在飞语境**，
