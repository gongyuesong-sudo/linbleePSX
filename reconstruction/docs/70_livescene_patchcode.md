# 70 — A3 楔4：BIOS 镜像是活现场——运行时补丁码区与中断服务表（task-086，SESSION-95）

## 1. 决定性勘正：golden 的 BIOS 镜像区被运行时改写（RAM≠ROM）
五点双源对照（RAM vs ROM 全 DIFF）：`0x5A314/0x5A1D8/0x5ABA0/0x79D00/0x79B54`。
RAM 侧反汇编**全部合法 MIPS**：`lui at,0x8008 / sw zero,at,0x9d4c / jal 0xB001ABxx /
lw t9,t9,0x9d44 + 间接调用`——正是 docs/47 设备访问族签名。
**判读**：0x5Axxx = BLEEM **运行时自适应补丁码区**（改写 BIOS 镜像 RAM），
guest 真执行的是 RAM 侧码（jit 行为一直如此，此前解剖一直拿 ROM 做基准是隐性错误——本楔勘正）。
`ra=0x8005A314` = `lw s4,sp,0x2c` 合法栈帧恢复指令（楔1 尸检中"ROM 乱码"疑云消除）。

## 2. `0x79D00` = 运行时函数指针表（t9 僵尸环恒定目标的身份）
表头：`[80079d18, 8005a844, 8005a380, 8005a160, 8005a424, 8005a5fc] + "intr" ".vc" 串`——
5 个函数指针全指 0x5A 码区；函数头解剖：状态词检查族（`lw t6,0x9d48`+条件分支）、
参数表索引族（`0x800EFFEE0 + a0*4`）。字符串 "intr"/".vc" = **中断/控制台服务族**。
MAINRUN 末态 `v0=8005a844` = 表槽[1]——僵尸环在反复回到中断服务入口。
