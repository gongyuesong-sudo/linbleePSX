## 终判要点
1. C1 侧 rootcall 服务为**寄存器 ABI、零帧**：handler 只需 a0-a3/t1(cmd)/t2(向量) 与 `jr ra` 回存，不需建帧。
2. cmd=0x12/0xb 的字符串参数在 **sp+0x20 以下的调用者帧内**（ASCII 实锤 `right91 ts`/`20/4`），handler 读 a1/a2 指针即可。
3. C2→C1 反向调用（0x6c/0xe4/0xfc/0x1c8）实测分布在 **4 个不同栈窗口**：801ffdc8（C2main@0x30010/0x3002c）、801ffd18（0x3086c/0x3087c/0x30884）、801ffd58（0x54230，帧内含 ASCII "Copyri...ght91 t"）、801ffd00（0x5462c）——全部 ≠ boot 栈 801ffe00，线程隔离栈直接实证 docs/36 §6 调度面。注意 boot/线程栈窗口 [0x1ffd2c] 在 golden 终态为 0x400（帧已弹出后的残值，非返回地址），而 [0x1ffdcc]=4 是 SESSION-57 定样的合法深层 init 残值，ra=4 halt 正是冷链缺线程切换、把 boot 栈残值当活帧读的必然后果。H-24b 建线程帧：按 C2 CreateThread 语义给顺序流建独立栈帧。
4. C2 反向调用把 BIOS ROM 数据区指针（a1/a2=bfc7fff0/bfc7ff91，版本串区）作为参数——C1 服务侧只读，无需建模写入。
