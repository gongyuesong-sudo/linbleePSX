# 62 — H-27 楔1：设备真装四段链与 0x3d 形态剧变（task-077，SESSION-86）

## 0. 本线立场（与 H-25/26 的本质区别）
H-25/26 钩（RAFIX/ZEROFIX）= **宿主伪造完成**（v0 造值）；H-27 = **真实设备实装**——
guest 每一步都是真执行，宿主只把设备侧的语义补全。判据也不同：完成 = 真跑完，不是被接管。

## 1. 四段设备真装链（全部实测，逐段推进 halt 点位）
| 段 | 语义缺口 | 能力 | 0x3d 形态 |
|---|---|---|---|
| 1 | **I_MASK(0x1074) 恒 0 → `I_STAT&I_MASK` 交始终假 = 一切中断等待永假**（此前 EVTGEN 零增益的总根因） | `H_IRQMASK=0xFFFFFFFF` | 119,220 死 → **9,748 块过轮询** |
| 2 | I_STAT 写清语义（写 0 位清；guest 写 ffffffff=全不清是**正确真机行为**，宿主覆写语义此前偶然放行） | `H_ISTATCLR` | 组合下 117k-147k 深推进 |
| 3 | 事件流置位 | `H_EVTGEN=0x1` | 活着跑满预算（不死） |
| 4 | **C2 引擎私有 MMIO 0x1F801040-4F 握手面**：写窗 0x1044(RMW) + 状态读回窗 0x104A(lhu) 双相位 bit0/bit1 逐字节握手 | `H_I044OK`（段初版只置 0x1044=打错端口, 298k 环实证；扩 0x104A 后通） | 0x456c→0x45c4→**4M 块过全部握手, 推进到 C2 深码 0x80059ed8** |

## 2. 形态剧变（本楔主证）
无 RAFIX/ZEROFIX 辅助：`0x3d` 从「119,220 块 epilogue 死跳」→「**16M 块持续真执行**」，
halt 点位 = 合法函数入口 `0x80059ed8`（andi/slti/jr ra）——服务在真跑长任务/等新数据，**不是死**。
「静态注入穷尽」的 H-26 终判在本线被部分改写：**设备面补全能把死墙变成活循环**；
0x3d 真完成(rc=0)仍差事件数据源（下一步）。

## 3. 假阳性门
基线全序（无任何 H-27 env）恒 `ok=2 ctx=22` 逐字不变；四段各自单开无破坏（host67 C/D）。
