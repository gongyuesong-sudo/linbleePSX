# 54 — M-11 批3楔子2：0x19 终证=线程调度器读回收语境（task-068，SESSION-77）

## 1. 决定性证据链（b0/19，118,051 块最深非 waiter）
1. `FWDSBW` 单事件：blocks=117,851 处 `sp: 0x801ffe00 → 0x000085d8, ra=0x00000e10`——boot 栈一次跳到裸低页。
2. `FWDSPW` 零事件：FWDSERVE 影子栈 512 层全程父 sp 合法 → 污染源在 **guest 自身控制流**，宿主机制无罪。
3. 落点解剖：golden `RAM[0x85D4]=0x00000e10`（ra 来源）；`RAM[0xE00..0xE34]` = **C2 运行时 thunk 池**
   （`beq/jalr r31,r17 / addu r4,r2,r0; jalr r31,r16` 型转发叶函数）。
4. 终跳 `EMITFAIL pc=000026f0 op=0`（RAM[0x26F0]=0 数据页当码执行）。
5. 函数 `0x80058628` 现场：`lui r5,0x8008; lw r5,9c44(r5); lw r14,4(r5); andi r15,r14,8; bne`——
   读 **RAM[0x80089C44] 对象的 flag bit3**，而金标终态该槽 = **0xFEFF0002（状态词，非指针）**。
6. t=5s 早期态该槽同为 0xFEFF0002、`[0x68]=0xFF`（哨兵已立）——boot 在 5s 前已完成，**任何采集时点的终态 RAM
   都不含活线程上下文**。

## 2. 终判
`b0/19` = **线程调度/切换服务**：它要恢复的 TCB 语境（sp=0x85D8 指向的栈帧+thunk 返回链）只存在于
**线程运行中的机器**，boot 完成后的快照里语境已回收。→ 转化 0x19 的**唯一路径=真线程调度器**
（建 TCB + 线程栈 + 事件生产者，使其"活着被调用"），任何 RAM 补数据都不可救。
这是 docs/44/45/53 的"事件生产者+调度器墙"在**单服务粒度**的完整闭环实证。

## 3. IRQ 轮询族补强
`H_POLLPC` 分型：I_STAT(0x1F801070) 消费点=pc 0（经 0x19 族调度器循环），值 1..11 环扫 =
**12 中断源位巡扫**（与 ROM 唯一直接读点 `bfc15f30` 的 I_STAT 处理族一致）——等待语义再证。

## 4. 顺带修正
`b0/4a` 与 `b0/45` 独跑/全序双态恒 `rc=0`（blocks 2/4，v0=0/1 幂等快服务）——**docs/51 的
"45/4a 批次态依赖（孤跑 BREAK、全量序 HALT）"定性在本轮快照下不复现，予以作废**。
当前全序转化恒为 ok=2 = {0x45, 0x4a}；其余 22 全为 §2 语境界。
